# zkmsg GUI + core-library refactor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Split `tools/zkmsg` into a `zkmsg-core` library + `zkmsg` CLI + `zkmsg-gui` egui app, add pipeline progress events (CLI output byte-identical), and ship a native macOS GUI that drives a real Sepolia send.

**Architecture:** One cargo workspace at `tools/zkmsg/` with three member crates. The lib holds all logic (crypto/tree/args/pack/chain/pipeline/state/config/inbox) and emits `PipelineEvent`s through a sink closure instead of `println!`. The CLI passes a sink that reproduces today's stdout; the GUI passes a sink that forwards events over an mpsc channel to an egui repaint loop, with one worker thread owning each blocking send.

**Tech Stack:** Rust (existing deps), egui/eframe 0.29 for the GUI, `std::sync::mpsc` + `std::thread` (no async runtime). macOS/Apple Silicon native.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-07-07-zkmsg-gui-design.md`.
- **Platform: macOS/Apple Silicon native only.** No cross-compilation, no CI matrix, no bundling/signing.
- **CLI parity gate**: after the refactor the `zkmsg` binary's commands, flags, and stdout must be byte-identical to today's. This is a hard gate on Task 3.
- Pipeline stays SYNCHRONOUS and blocking; no async runtime. Concurrency is plain `std::thread` + `mpsc`.
- Never block the egui UI thread on RPC/subprocess/receipt calls — always a worker thread feeding the channel.
- A send costs ~46–48 STRK; the GUI must gate it behind an explicit STRK-cost confirmation.
- The workspace stays self-contained (its own `[workspace]`, not joining any parent).
- Existing 27 core unit tests must stay green throughout; commit per task.
- Build/test from `tools/zkmsg/`. scarb/snforge are unrelated here; this is pure cargo.
- Deployed store `0x02d66a02b2efdddb5282bf7d7931cbb7a724f191478843b1fccbf3b9729e91b7`; identities `~/.zkmsg` (alice), `~/.zkmsg-bob` (bob).

- [ ] **Step 3: Add the enum and helper**, near the top of `pipeline.rs`:

```rust
#[derive(Debug, Clone)]
pub enum PipelineEvent {
    StepStarted { index: usize, total: usize, kind: StepKind },
    TxSubmitted { kind: StepKind, tx_hash: String },
    StepCompleted { kind: StepKind, tx_hash: Option<String>, note: Option<String> },
    Completed { fact: Option<String> },
}

/// Emits a StepStarted for each still-pending step without executing —
/// lets a UI render the plan and lets tests assert event shape offline.
pub fn emit_plan_events(state: &SendState, sink: &mut dyn FnMut(PipelineEvent)) {
    let total = state.steps.len();
    for (index, step) in state.steps.iter().enumerate() {
        if !step.done {
            sink(PipelineEvent::StepStarted { index, total, kind: step.kind.clone() });
        }
    }
}
```

- [ ] **Step 4: Thread the sink through `run`.** Replace the current `run` body:

```rust
pub fn run(
    &self,
    state: &mut SendState,
    sink: &mut dyn FnMut(PipelineEvent),
) -> Result<()> {
    fs::create_dir_all(self.workdir(state))?;
    while let Some(index) = state.next_pending() {
        let kind = state.steps[index].kind.clone();
        let total = state.steps.len();
        sink(PipelineEvent::StepStarted { index, total, kind: kind.clone() });
        let (tx, note) = self.execute(state, &kind)?;
        if let Some(h) = &tx {
            sink(PipelineEvent::TxSubmitted { kind: kind.clone(), tx_hash: h.clone() });
        }
        state.mark_done(index, tx.clone(), note.clone());
        state.save(self.home)?;
        sink(PipelineEvent::StepCompleted { kind, tx_hash: tx, note });
    }
    sink(PipelineEvent::Completed { fact: state.fact.clone() });
    Ok(())
}
```

```rust
use std::sync::mpsc::{Receiver, Sender, channel};
use std::thread;
use zkmsg_core::config::{Config, Home};
use zkmsg_core::pipeline::{Pipeline, PipelineEvent};
use zkmsg_core::state::SendState;

pub enum WorkerMsg {
    Progress(PipelineEvent),
    Done(Result<(), String>),
}

/// Runs (or resumes) a send on a worker thread; the returned receiver
/// yields progress until Done. `ctx` is repainted on each message.
pub fn spawn_send(
    home: Home, config: Config, mut state: SendState, ctx: egui::Context,
) -> Receiver<WorkerMsg> {
    let (tx, rx): (Sender<WorkerMsg>, Receiver<WorkerMsg>) = channel();
    thread::spawn(move || {
        let tx2 = tx.clone();
        let ctx2 = ctx.clone();
        let mut sink = move |e: PipelineEvent| {
            let _ = tx2.send(WorkerMsg::Progress(e));
            ctx2.request_repaint();
        };
        let result = Pipeline::new(&home, &config).run(&mut state, &mut sink);
        let _ = tx.send(WorkerMsg::Done(result.map_err(|e| format!("{e:#}"))));
        ctx.request_repaint();
    });
    rx
}
```

(Note: `egui::Context` re-exported via `eframe::egui`; import accordingly.)
